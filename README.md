# reconditioning_website

Reconditioning Programme Tracker

Open index.html in any modern browser.

Use:
1. Enter the programme start date.
2. The app calculates the correct programme week and phase.
3. It shows only the current week and today's work.
4. Record weekly walking minutes, sessions, strength, conditioning, mobility, pain, weight, waist and notes.
5. Progress is saved locally in the same browser.
6. Use Export CSV to download progress data.

No internet connection is required. No data is sent anywhere.
